# VisualClaw MVP PRD

- **版本**：v0.1
- **日期**：2026-05-03
- **状态**：草案
- **项目名**：VisualClaw
- **目标平台**：Windows / WSL
- **形态**：轻量桌面客户端（优先），内嵌本地 Web UI 或等价视图

## 1. 产品概述

### 1.1 产品背景

OpenClaw 当前以命令行与 Web 控制台为主。对于新手用户来说，直接面对 CLI 和多层配置成本较高，容易在“安装、连接、找功能、跑命令”这些环节产生阻塞。

本项目要做的是一个**小白可用的桌面 UI**：
- 能自动找到本机已安装的 OpenClaw
- 能把常用命令做成自然、低打扰的按钮
- 能尽量复刻现有 Web UI 的核心能力，但不把复杂度原样搬过来

### 1.2 产品目标

- 降低 OpenClaw 的上手门槛
- 让用户无需记忆命令行即可完成高频操作
- 自动检测并连接本机 OpenClaw 实例
- 初期覆盖 Windows 与 WSL 两种安装环境
- 以“可用优先”，后续再逐步原生化和增强

### 1.3 产品范围

#### MVP 范围内
- 自动扫描本机端口并识别 OpenClaw 服务
- 显示连接状态、实例信息、基础健康状态
- 复刻 Web UI 的核心页面能力：
  - 首页/状态
  - 会话
  - 任务
  - 日志
  - 配置
  - 连接管理
- 常用命令按钮化：启动、停止、重连、刷新、打开日志、进入会话/任务等
- 手动指定端口/地址作为兜底
- Windows / WSL 识别与适配

#### MVP 不包含
- 插件市场
- 多用户协作
- 远程多实例统一编排
- 复杂工作流编排器
- 高级主题系统
- 完整命令行全集的逐项可视化

### 1.4 核心原则

1. **先复刻能力，再优化体验**
2. **高频显性，低频隐藏**
3. **默认简单，必要时再展开**
4. **不让 UI 变成命令行的翻版**

## 2. UML 用例模型

### 2.1 参与者

- **新手用户**：首次接触 OpenClaw，依赖 UI 完成基础操作
- **熟练用户**：知道 OpenClaw 能力，希望更快入口
- **本地 OpenClaw 服务**：被 UI 发现并连接的目标服务
- **系统环境**：Windows / WSL，用于端口扫描、路径识别、进程判断

### UC-01 自动发现本地 OpenClaw 实例

| 项目 | 内容 |
|---|---|
| **用例编号** | UC-01 |
| **用例名称** | 自动发现本地 OpenClaw 实例 |
| **参与者** | 新手用户、系统环境 |
| **优先级** | 高 |
| **前置条件** | 客户端已启动 |
| **后置条件** | 成功识别一个或多个可连接实例，或进入手动配置兜底 |

| **备选事件流** | 1a. 未发现实例：提示用户手动输入端口/地址。<br>2a. 发现疑似实例但无法验证：标记为“待确认”。 |

#### 数据说明表

**本地实例发现结果（local_instance_discovery）**

| 字段名 | 字段中文名 | 数据类型 | 取值范围 | 是否必填 | 备注说明 |
|---|---|---|---|---|---|
| instance_id | 实例 ID | STRING | 任意字符串 | 是 | 本地唯一标识 |
| host | 主机地址 | STRING | IP/localhost | 是 | 如 127.0.0.1、localhost |
| port | 端口 | INT | 1-65535 | 是 | 探测到的端口 |
| status | 状态 | ENUM | FOUND/PENDING/FAILED | 是 | 发现状态 |
| env_type | 环境类型 | ENUM | WINDOWS/WSL/UNKNOWN | 是 | 运行环境 |
| score | 匹配分 | INT | 0-100 | 否 | 推荐排序用 |

## 4. 详细交互设计

### 4.1 页面整体流程

```text
启动客户端
   │
   ├─► 自动扫描本机 OpenClaw
   │      │
   │      ├─► 找到实例 → 自动连接 → 进入首页
   │      │
   │      └─► 未找到实例 → 展示手动输入/重试
   │
   └─► 首页 → 会话 / 任务 / 日志 / 配置 / 连接管理
```

### 4.2 连接状态机

```text
[未连接]
   │ 自动扫描
   ▼
[发现实例]
   │ 连接成功
   ▼
[已连接]
   │ 断线 / 退出
   ▼
[连接失败]
   │ 重试 / 手动配置
   └──────────────► [未连接]
```

### 4.3 时序图：自动发现并连接

```text
用户            客户端UI            本地扫描器            OpenClaw服务
 │                 │                   │                    │
 │ 启动客户端      │                   │                    │
 │────────────────►│                   │                    │
 │                 │ 启动端口扫描       │                    │
 │                 │──────────────────►│                    │
 │                 │                   │ 探测服务           │
 │                 │                   │──────────────────►│
 │                 │                   │  返回响应          │
 │                 │                   │◄──────────────────│
 │                 │ 选择最佳实例       │                    │
 │                 │ 连接               │──────────────────►│
 │                 │                   │                    │ 返回成功
 │                 │◄───────────────────────────────────────│
 │ 查看首页        │                   │                    │
```

### 4.4 追问/异常流程

- 未找到服务：显示“未发现 OpenClaw” + 手动输入端口 + 重试
- 多个实例：显示推荐项，并提供下拉选择
- 连接后断开：保留当前页面，顶部显示断线条幅
- 配置失败：不清空已填内容，允许回退

## 5. UI 设计规范

### 5.1 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 / 连接状态 / 搜索 / 常用动作                       │
├──────────────┬───────────────────────────────────────────────┤
│ 左侧导航      │ 主内容区                                      │
│ - 首页        │ 状态卡 / 列表 / 详情 / 空状态                 │
│ - 会话        │                                               │
│ - 任务        │                                               │
│ - 日志        │                                               │
│ - 配置        │                                               │
│ - 连接管理    │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

### 5.2 组件原则

- **首页状态卡**：只放最重要的 3-5 个指标
- **常用按钮**：主按钮最多 5 个，其他放“更多”
- **高级命令面板**：默认隐藏，快捷键呼出
- **列表页**：以“最近 + 搜索 + 详情”三段式为主
- **错误提示**：短句、明确、可操作

### 5.3 视觉规范

- 风格：清爽、克制、低学习成本
- 主色：OpenClaw 品牌色（待定）
- 背景：浅色优先，支持深色模式作为二期
- 字体：系统默认字体优先，避免引入额外复杂性
- 间距：8px 基线网格

### 5.4 交互规范

- 默认页进入后自动聚焦“连接状态”
- 切页不丢失当前筛选条件
- 危险操作必须二次确认
- 失败提示必须附带“重试/修改/查看详情”至少一个动作

### 5.5 页面按钮与 Tab 说明

#### 顶栏按钮
- **连接状态**：显示当前是否已连上 OpenClaw，支持点击查看详情。
- **搜索**：快速检索会话、任务、日志、配置项。
- **刷新**：重新拉取当前页面数据。
- **重连**：重新扫描并连接本机实例。
- **高级命令面板**：呼出输入式命令入口，给熟练用户用。

#### 左侧 Tabs
- **首页**：总览当前连接、最近会话、最近任务和快捷入口。
- **会话**：查看会话列表、筛选、进入详情。
- **任务**：查看任务列表、状态、进度和执行记录。
- **日志**：查看运行日志、错误和排查信息。
- **配置**：查看/修改常用配置。
- **连接管理**：管理自动发现结果、手动端口、目标实例切换。

#### 首页快捷按钮
- **一键连接/重连**：在未连接、断线时快速恢复。
- **打开会话**：直接进入会话页。
- **打开任务**：直接进入任务页。
- **打开日志**：快速定位问题。
- **打开配置**：进入基础设置。
- **更多**：收起低频操作，避免首页过重。

## 6. 非功能需求

### 6.1 性能

- 客户端冷启动后 3 秒内完成首次扫描开始
- 自动发现流程不应阻塞主界面响应
- 页面切换需保持流畅

### 6.2 兼容性

- Windows 10/11
- WSL2
- 本机回环地址 / 常见本地端口

### 6.3 安全

- 默认仅连接本机实例
- 不主动暴露远程访问能力
- 手动配置需明确提示风险
- 日志与配置编辑需避免误操作覆盖

### 6.4 可靠性

- 连接失败可重试
- 自动发现失败可手动兜底
- UI 不可因单个页面数据缺失而崩溃
