# VisualClaw MVP Test Cases

- **版本**：v0.1
- **日期**：2026-05-06
- **来源**：`docs/MVP.md`
- **范围**：VisualClaw MVP

## 1. Test Scope Summary

### 目标
验证 VisualClaw MVP 是否满足 PRD 中的核心路径：
- 自动发现本机 OpenClaw
- 连接 / 重连
- 首页状态展示
- 会话 / 任务 / 日志 / 配置 / 连接管理页面
- 常用命令按钮化
- Windows / WSL 适配
- 手动兜底

### 不在本次测试范围
- 插件市场
- 多用户协作
- 远程多实例统一编排
- 复杂工作流编排器
- 高级主题系统
- 完整命令行全集可视化
- 聊天式对话功能（PRD 未要求）

## 2. Test Points by Module

| 模块 | 测试重点 |
|---|---|
| 自动发现 | 扫描端口、识别服务、多实例排序、失败兜底 |
| 连接管理 | 连接成功、断线重试、手动 host/port、错误提示 |
| 首页 | 状态、实例信息、最近会话/任务摘要、空态引导 |
| 会话 | 列表、详情、搜索、无数据态 |
| 任务 | 列表、详情、状态区分、无数据态 |
| 日志 | 最近日志、搜索、跳转入口、无数据态 |
| 配置 | 查看、编辑、保存、读取失败兜底 |
| 常用命令 | 按钮可见性、文案、执行结果、危险操作确认 |
| 环境识别 | Windows / WSL 策略切换、通用兜底 |
| 非功能 | 启动不阻塞、页面流畅、错误可恢复 |

## 4. Open Questions

1. 首页“最近任务/会话摘要”是否需要明确条数上限？
2. 手动连接是否允许保存多个目标地址？
3. 高危命令的清单是否需要产品再补一版白名单？
4. 会话详情是否只读，还是允许发起基础操作？
