# VisualClaw

## Goal
Build a lightweight Windows/WSL desktop client for OpenClaw MVP.

## MVP scope
- Auto-discover local OpenClaw instances
- Connect / reconnect to an instance
- Show home, sessions, tasks, logs, config, connection management
- Expose common actions as buttons

## Out of scope
- Plugin marketplace
- Multi-user collaboration
- Remote multi-instance orchestration
- Complex workflow builder
- Full command-line parity

## Working rules
- Prefer simple, usable UI over full native complexity
- Reuse existing OpenClaw ideas and APIs where possible
- Keep project docs under docs/
- Verify changes before closing a task

## Suggested commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`

## Acceptance for the first milestone
- Project skeleton exists
- App starts locally
- Basic placeholder pages for core sections exist
- CLAUDE.md and docs are present
